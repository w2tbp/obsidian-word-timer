# 写作字数计时器

像番茄钟一样的写作字数计时器，帮助你专注于写作并实时追踪进度。

## 功能特性

- **实时状态栏显示**：⏱ 用时 05:32 · 净增 328 字 · 59 字/分（每秒刷新）
- **三个核心命令**：
  - 开始写作计时
  - 暂停/继续计时
  - 结束计时并查看汇总
- **Ribbon 图标**：点击侧边栏图标快速开始/结束计时
- **净增字数统计**：只计算会话开始后的新输入，删除会减少净增（最低为 0）
- **支持跨文件**：在会话中切换文件不会清零或重复累加计数
- **暂停冻结**：暂停期间计时和计数都冻结，不统计暂停时的输入

## 安装方式

1. 下载或克隆本项目到本地
2. 将 `obsidian-word-timer` 文件夹复制到你的 Obsidian vault 的 `.obsidian/plugins/` 目录下
3. 打开 Obsidian，进入 设置 → 第三方插件
4. 启用「写作字数计时器」插件

## 使用方法

### 开始计时

- 方法 1：按 `Ctrl/Cmd + P` 打开命令面板，输入「开始写作计时」
- 方法 2：点击左侧 Ribbon 栏的时钟图标

### 暂停/继续

- 按 `Ctrl/Cmd + P`，输入「暂停/继续写作计时」
- 暂停期间状态栏显示「⏸」标识，计时和计数都冻结

### 结束计时

- 方法 1：按 `Ctrl/Cmd + P`，输入「结束写作计时」
- 方法 2：再次点击 Ribbon 栏的时钟图标
- 结束后会弹出 Notice 汇总：用时、净增字数、平均每分钟字数

## 设置项

在 设置 → 写作字数计时器 中可配置：

### 统计口径

- **字数**（默认）：中文按字算（每个 CJK 字符 = 1），英文/数字按词算（连续字母数字串 = 1），标点和空白不计
- **字符数**：包含所有字符（含标点和空格），用于对照

### 显示每分钟字数

- 开启（默认）：状态栏显示「X 字/分」
- 关闭：状态栏只显示用时和净增

## 计数口径说明

### 字数模式

- 中文字符：每个字算 1（包括 CJK 统一汉字、扩展 A 区等）
- 英文单词：连续的字母或数字串算 1 个词
  - 例如：`hello` = 1 词，`hello123` = 1 词，`hello world` = 2 词
- 混合文本：`你好world` = 3（2 个中文字 + 1 个英文词）
- 标点和空白：不计入

### 字符数模式

- 所有字符都计入，包括中文、英文、数字、标点、空格、换行等
- 等同于 `text.length`

### 净增计算

- 会话开始时，记录每个文件的基准字数
- 净增 = Σ max(0, 当前字数 - 基准字数)
- 删除会让净增减少，但最低为 0（不会为负）
- 暂停期间不追踪变化，恢复后从暂停前的状态继续

### 跨文件支持

- 每个文件独立维护基准和当前计数
- 切换文件不会清零或重复累加
- 净增是所有文件的累计值

## 技术实现

- 纯 JavaScript 插件，无构建步骤，无 npm 依赖
- 核心计数逻辑抽离到 `lib/counter.js`，可独立测试
- 使用 Obsidian API：`editor-change` 事件监听编辑器变化
- 状态栏每秒刷新一次

## 已知限制

- 暂停期间如果切换文件，恢复后需要手动触发一次编辑才能同步当前文件状态
- 如果会话开始时文件已有内容，会将当前内容作为基准（不计入净增）
- 只统计可见的编辑器内容，不包含折叠或隐藏的部分

# 写作字数计时器

像番茄钟一样的写作字数计时器，帮助你专注于写作并实时追踪进度。

## 功能特性

- **实时状态栏显示**：⏱ 用时 05:32 · 净增 328 字 · 59 字/分（每秒刷新）
- **三个核心命令**：
  - 开始写作计时
  - 暂停/继续计时
  - 结束计时并查看汇总
- **Ribbon 图标**：点击侧边栏图标快速开始/结束计时
- **净增字数统计**：只计算会话开始后的新输入，删除会减少净增（最低为 0）
- **支持跨文件**：在会话中切换文件不会清零或重复累加计数
- **暂停冻结**：暂停期间计时冻结，输入不计入净增；恢复后从暂停前的计数连续继续

## 安装方式

1. 下载或克隆本项目到本地
2. 将 `obsidian-word-timer` 文件夹复制到你的 Obsidian vault 的 `.obsidian/plugins/` 目录下
3. 打开 Obsidian，进入 设置 → 第三方插件
4. 启用「写作字数计时器」插件

## 使用方法

### 开始计时

- 方法 1：按 `Ctrl/Cmd + P` 打开命令面板，输入「开始写作计时」
- 方法 2：点击左侧 Ribbon 栏的时钟图标

### 暂停/继续

- 按 `Ctrl/Cmd + P`，输入「暂停/继续写作计时」
- 暂停期间状态栏显示「⏸」标识，计时冻结

### 结束计时

- 方法 1：按 `Ctrl/Cmd + P`，输入「结束写作计时」
- 方法 2：再次点击 Ribbon 栏的时钟图标
- 结束后会弹出 Notice 汇总：用时、净增字数、平均每分钟字数

## 设置项

在 设置 → 写作字数计时器 中可配置：

### 统计口径

- **字数**（默认）：中文按字算（每个 CJK 字符 = 1），英文/数字按词算（连续字母数字串 = 1），标点和空白不计
- **字符数**：包含所有字符（含标点和空格），用于对照

### 显示每分钟字数

- 开启（默认）：状态栏显示「X 字/分」
- 关闭：状态栏只显示用时和净增

## 计数口径说明

### 字数模式

- 中文字符：每个字算 1（包括 CJK 统一汉字、扩展 A 区等）
- 英文单词：连续的字母或数字串算 1 个词
  - 例如：`hello` = 1 词，`hello123` = 1 词，`hello world` = 2 词
- 混合文本：`你好world` = 3（2 个中文字 + 1 个英文词）
- 标点和空白：不计入

### 字符数模式

- 所有字符都计入，包括中文、英文、数字、标点、空格、换行等
- 等同于 `text.length`

### 净增计算

- 会话开始时，记录每个文件的基准字数
- 净增 = Σ max(0, 当前字数 - 基准字数)
- 删除会让净增减少，但最低为 0（不会为负）
- 暂停期间仍记录文本变化，但不计入净增；恢复时把暂停期间的变化量吸收进基准，保证暂停前后净增连续

### 跨文件支持

- 每个文件独立维护基准和当前计数
- 切换文件不会清零或重复累加
- 净增是所有文件的累计值

## 技术实现

- 纯 JavaScript 插件，无 npm 依赖
- 核心计数逻辑抽离到 `lib/counter.js`，可独立测试；发布时由 `build.js` 内联进 `dist/main.js`
- 使用 Obsidian API：`editor-change` 事件监听编辑器变化
- 状态栏每秒刷新一次

## 已知限制

- 只统计可见的编辑器内容，不包含折叠或隐藏的部分

## 开发

运行测试：

```bash
npm test
```

构建发布包：

```bash
npm run build
```

构建产物在 `dist/` 目录，包含 `main.js`、`manifest.json`、`styles.css`。

## 发布流程

1. 更新 `manifest.json` 和 `package.json` 中的 `version` 字段
2. 提交变更：`git commit -am "bump version to 0.x.x"`
3. 打 tag：`git tag v0.x.x`
4. 推送 tag：`git push origin v0.x.x`

GitHub Actions 会自动：
- 运行测试（`node --test`）
- 构建 bundle（`node build.js`）
- 校验 manifest 版本与 tag 一致
- 创建 GitHub Release，上传 `main.js`、`manifest.json`、`styles.css` 和 `obsidian-word-timer-<version>.zip`

用户通过 Obsidian 社区插件或 BRAT 安装时，会下载 release 中的这三个文件（不进入子目录）。

## 打包原理

`build.js` 把 `lib/counter.js` 内联进 `main.js`，替换掉 `require('./lib/counter')`，产出零相对依赖的单文件 bundle。这样 Obsidian 只下载 `main.js` 也能正常运行。

测试覆盖（36 个用例）：
- 字数统计（中文/英文/混合/标点/空串/多行/非字符串输入）
- 字符统计（含标点空格/空串/非字符串）
- 口径切换（word ↔ character）
- 净增只增不减（最低为 0）
- 暂停冻结计时，恢复后净增连续、暂停输入不补计
- 跨文件累计与切换文件不清零
- 会话重置（stop 后重新 start）
- 停止汇总（elapsed / netIncrease / unit）
- 暂停时长不计入 elapsed
- 首次打开已有内容文件不计入（跨文件基准）
- 口径切换重置基准（word ↔ character 切换后净增归零）
- 打包产物验证（dist/main.js 无相对依赖、可实例化、含内联 counter 代码）
